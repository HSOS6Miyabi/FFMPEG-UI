# 产品功能评估

## 评估范围

本次检查覆盖 Windows 和 Linux 界面、任务控制、FFmpeg 参数生成、ZIP/PPTX 处理、SSH 远程编码、配置保存、自动构建和使用文档。

## 当前已经具备的功能

- 支持单个视频、多个视频、文件夹、ZIP 和 PPTX。
- 支持 H.264、H.265、AV1，以及 CPU、NVIDIA NVENC、Intel Quick Sync 和 AMD AMF。
- 提供 CRF 数值、八档压缩级别、MP4 和源文件容器两种输出模式。
- 支持批量队列、并行调度、暂停、继续、取消、重复处理检查和结果大小统计。
- 支持 SSH 密钥、SSH Agent 和密码认证，并能在远程 Linux 服务器上执行 FFmpeg。
- 支持任务清单导入导出，Windows 和 Linux 都有原生桌面界面。

## 本轮完成的功能

### 输出分辨率

增加原始尺寸、2160p、1440p、1080p、720p 和 480p 六档设置。程序保持原始宽高比，不会放大低分辨率视频。分辨率设置参与重复处理检查和输出文件命名。

### 音频处理

增加自动编码、保留原音频和移除音频三种方式。保留原音频时直接复制音轨；目标容器不支持源音频编码时，程序会报告转换失败并保留原始文件。

### 自动恢复任务列表

程序会自动保存待处理文件路径。重新启动后恢复任务，并重新检查已有输出。用户仍然可以导入或导出 .ffq 文件，在不同设备之间迁移任务。

### 桌面界面调整

Windows 和 Linux 的编码设置区域采用左侧参数名称、右侧操作控件的布局。新增的分辨率和音频处理选项与原有 CRF、压缩级别和音频码率设置使用相同的视觉样式。

## 后续功能建议

以下项目在本轮检查中尚未发现对应实现，建议按用户收益和开发成本安排后续工作。

| 优先级 | 功能 | 当前情况 | 建议实现内容 |
|---|---|---|---|
| 高 | 视频信息查看 | 添加文件后主要显示文件名、状态和进度 | 显示分辨率、时长、帧率、视频编码、音频编码和文件大小；探测工作放入后台线程 |
| 高 | 自定义编码预设 | 目前提供固定的八档压缩级别 | 支持保存、重命名、删除和导入导出自定义预设，记录视频编码、设备、CRF、分辨率和音频设置 |
| 高 | 字幕处理 | 当前默认不复制字幕流和数据流 | 提供保留兼容字幕、选择字幕轨道和移除字幕的选项，并检查不同容器的字幕兼容性 |
| 中 | 输出文件大小目标 | 当前由 CRF 和压缩级别控制画质 | 增加目标大小或目标平均码率模式；需要评估双遍编码时间和硬件编码器差异 |
| 中 | 逐任务参数设置 | 当前一批任务共用一组编码设置 | 允许为单个任务覆盖分辨率、音频和质量设置，同时保留批量默认值 |
| 中 | 视频预览 | 当前没有内置播放器和压缩前后对比 | 支持调用系统播放器预览源文件与输出文件，后续再考虑内置播放和画面比较 |
| 中 | 诊断日志导出 | 任务详情会显示错误信息，缺少统一的诊断包 | 提供脱敏后的 FFmpeg 命令、错误输出、应用版本和环境信息导出 |
| 中 | 安装包 | 当前发布 ZIP 和 tar.gz 压缩包 | 增加 Windows 安装程序、Linux 桌面启动项和卸载流程 |
| 低 | 完成通知 | 任务完成后主要依赖界面状态 | 增加 Windows 通知和 Linux 桌面通知，并提供开关 |
| 低 | 版本更新检查 | 当前依赖用户自行查看 GitHub Release | 提供版本检查和发布说明入口，下载与安装由用户确认 |

## 开发注意事项

- 视频信息探测和缩略图生成应在后台线程执行，避免打开大量文件时阻塞界面。
- 自定义预设和逐任务参数应复用 ConversionSettings，避免在平台界面中分别实现编码规则。
- 字幕复制需要按目标容器和字幕编码判断兼容性。不能直接把所有字幕流复制到每种容器。
- 目标文件大小模式应明确区分平均码率估算与实际输出大小。需要对不同编码器进行单独测试。
- 当前程序要求系统安装 FFmpeg 和 ffprobe，并能从命令行访问。若以后随安装包提供 FFmpeg，需要检查不同平台的分发许可和更新方式。
- 任何新增参数都必须参与处理参数指纹、输出命名、直接视频测试和 ZIP/PPTX 内部视频测试。
- 修改界面后，必须分别运行 Windows 和 Linux 程序并检查实际截图，检查常用窗口尺寸、DPI 缩放、深浅色外观和长文件名。

## 当前验证要求

- Linux：CMake 构建、核心单元测试、FFmpeg 转换、音频复制与移除、分辨率缩小、ZIP、PPTX 和 SSH 集成测试。
- Windows：MSVC 构建、核心单元测试、FFmpeg 转换、音频处理和分辨率设置测试。
- 桌面界面：检查参数名称与控件是否重叠，检查鼠标点击区域与显示位置是否一致。
- 硬件编码：需要真实 NVIDIA、Intel 或 AMD 设备和对应驱动，CI 中的 CPU 测试不能替代硬件验证。
