# 产品功能评估

更新日期：2026-11-19。本文件记录已实现的功能、需要保留的用户体验和可考虑的后续功能。当前主分支的功能状态见[开发状态记录](development-checkpoint.md)，开发与验证记录见[维护台账](maintenance-ledger.md)。

## 已实现的功能

- 支持视频文件、文件夹、ZIP 和 PPTX 的导入与批量处理。目录和压缩包内部视频由后台线程枚举，队列逐步显示文件。
- 支持 H.264、H.265、VP9、AV1 和有条件可用的 H.266；支持 CPU、NVENC、Quick Sync 和 AMF，具体选项由当前 FFmpeg 与硬件探测结果决定。
- 提供八档压缩级别、质量数值、音频处理方式、六档输出分辨率，以及 MP4、MKV、WebM 或原格式输出。
- 每个视频独立保存裁剪起点与终点。ZIP/PPTX 内部视频可单独选中和调整裁剪范围，不会改变其他视频。
- Windows 和 Linux 可视化裁剪器支持画面预览、绿色起点游标、红色终点游标、蓝色预览位置游标，支持拖动和直接输入时间；预览解码在后台进行。
- 任务队列支持进度与文件大小统计、并行处理、暂停、继续、取消、失败任务重试、重复处理检查及自动恢复。
- `.ffq` 清单记录各视频裁剪范围，兼容旧版路径清单；支持手动导入导出。
- 支持通过 SSH 对远程 Linux 服务器执行视频转换，能够使用密钥、SSH Agent 或密码认证。
- Windows/Linux 原生桌面界面支持队列专注视图、失败筛选、深浅色主题、DPI 缩放和文件拖放。
- Windows 发布包含 FFmpeg、ffprobe 与第三方许可文件；提供 NSIS 安装程序和便携 ZIP，并有安装卸载自动化测试。

## 应保留的用户体验

- 用户添加 ZIP/PPTX 或目录后，应立即看到扫描状态和逐步出现的视频列表，不能因完整扫描、压缩包解压或画面提取而长时间无法操作窗口。
- 只有明确选中的视频才会修改裁剪起止时间；保存设置、重新启动和重新导入队列时，视频与裁剪范围的对应关系保持一致。
- 压缩包转换成功后，其他文件仍然保留；必要的媒体引用随视频扩展名变化更新。取消或处理失败时保留原始文件。
- Windows 与 Linux 的选项含义一致；时间轴、队列选中位置、DPI 缩放和小窗口布局均应通过实际截图检查。
- 只有编译、单元测试、实际媒体测试和界面测试全部通过，才可认为相应改动完成。正式发布还需确认版本与标签对应。

## 可考虑的后续功能

以下项目按照当前代码和使用体验划分优先级，属于建议范围。

| 优先级 | 项目 | 现有能力 | 建议补充 |
|---|---|---|---|
| 高 | 队列中的视频技术信息 | 已显示视频名称、状态、进度及部分文件大小 | 后台读取并显示时长、分辨率、帧率、编码格式和音轨信息 |
| 高 | 用户自定义编码预设 | 固定八档压缩级别 | 保存、重命名、导入和导出包含质量、容器、音频和分辨率的预设 |
| 高 | 字幕选择 | 当前默认不复制字幕流和数据流 | 允许选择、移除或保留与输出容器兼容的字幕轨道 |
| 中 | 输出文件大小目标 | 使用质量与压缩档位控制输出 | 增加目标大小或平均码率设置，并对双遍编码与硬件差异开展测试 |
| 中 | 单任务编码选项 | 每个视频已有独立裁剪范围，其他编码选项按批次共享 | 允许某个任务单独覆盖分辨率、音频处理和质量数值 |
| 中 | 视频播放与前后比较 | 可以提取指定时间的源画面 | 连续播放视频及比较转换前后的画质 |
| 中 | 诊断资料导出 | 界面显示状态和错误原因 | 导出经过隐私信息处理的 FFmpeg 命令、日志与运行环境信息 |
| 中 | Linux 安装体验 | 提供 tar.gz | 提供桌面启动项和卸载操作 |
| 低 | 完成通知 | 任务进度显示在程序窗口 | 支持 Windows/Linux 桌面完成通知和设置开关 |
| 低 | 版本检查 | GitHub Release 提供已发布版本 | 在界面中查看发布说明，并由用户确认下载或安装 |

## 功能开发注意事项

- 新增媒体探测任务时，优先使用后台线程；界面应实时展示进展，并允许用户在解码期间继续使用其他功能。
- 逐任务编码参数应由共享核心管理，保持与现有 `BatchItemSnapshot::trim`、`ConversionSettings` 和任务保存方式兼容。
- 修改字幕或音轨复制时，应先检查目标容器支持的编码和流类型。
- 目标文件大小属于估算性质，需要针对各编码器、不同媒体长度和输出容器进行实际测试。
- 变更用户可见功能时，分别运行 Windows 和 Linux 程序并检查真实截图。
- 各项功能的具体实现与测试责任见[接管与维护手册](handover.md)和[构建、测试与发布手册](ci-release.md)。
