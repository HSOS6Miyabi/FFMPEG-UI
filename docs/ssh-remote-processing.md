# SSH 远程编码

## 用途

SSH 远程编码让本机 FFmpeg Studio 借用远程 Linux 服务器的 CPU 或硬件编码器处理视频。用户仍然在本机选择源文件和输出位置。程序负责上传、远程转换、下载、检查结果和清理临时文件。

远程服务器不需要安装 FFmpeg Studio，也不需要运行常驻服务。

## 远程服务器要求

- Linux 或兼容 POSIX shell 的系统。
- 可以通过 OpenSSH 客户端连接。
- 安装 `ffmpeg` 和 `ffprobe`，并且两者可以从登录 shell 的 PATH 中找到。
- 远程账户可以在系统临时目录中创建文件，并运行 FFmpeg。
- 如果要使用 NVIDIA、Intel 或 AMD 硬件编码，需要安装对应驱动，并使用包含相应编码器的 FFmpeg 构建。

当前远程执行使用 `mktemp`、`kill`、`wc` 和 POSIX shell。Windows 本机可以连接远程 Linux 服务器；远程 Windows 主机尚未纳入支持范围。

## SSH 配置

程序读取当前用户的 SSH 配置：

- Windows：`%USERPROFILE%\.ssh\config`
- Linux：`$HOME/.ssh/config`

每个具体的 `Host` 别名会显示为一台服务器。通配符条目（例如 `Host *`）不会单独显示。

服务器管理器可以新增、修改和删除服务器配置。保存修改时，程序会保留同一 `Host` 块中其他别名以及未管理的 SSH 选项。程序只管理连接地址、用户名、端口、私钥路径、跳转服务器和认证方式。

私钥认证使用 `IdentityFile` 或 SSH Agent。密码认证使用 OpenSSH askpass 辅助程序；Windows 密码保存在 Windows Credential Manager 中，不写入 SSH 配置文件或命令行参数。

首次连接时，OpenSSH 使用 `StrictHostKeyChecking=accept-new` 接受新的主机密钥，并在后续连接中验证已保存的主机密钥。若主机密钥发生变化，连接会失败，需要用户检查服务器身份后再更新本机的 `known_hosts`。

## 任务处理过程

1. 程序连接 SSH 服务器并检查 FFmpeg、ffprobe、CPU、内存和可用编码器。
2. 程序在远程临时目录中创建独立任务目录。
3. 程序通过 SCP 上传源视频，保留源文件扩展名以便远程 FFmpeg 正确识别输入格式。
4. 程序使用用户选择的编码器、CRF、压缩级别、音频码率和输出容器执行 FFmpeg。
5. 程序读取 FFmpeg 的机器可读进度信息，并显示帧数、当前时间、速度和预计剩余时间。
6. 程序使用 ffprobe 检查输出容器、视频编码、音频编码和处理标记。
7. 程序通过 SCP 将输出下载到本机临时文件，检查下载大小后再移动到最终位置。
8. 任务结束后，程序删除远程临时目录。取消任务时会先尝试终止远程 FFmpeg 进程。

ZIP 和 PPTX 任务会复用相同的远程视频转换服务。压缩包或演示文稿仍在本机展开和重新打包，只有其中的视频文件会传到远程服务器。

## 安全与文件处理

- 所有本地源文件保持不变。
- 本机输出文件先下载到临时文件，完成大小检查后才替换最终文件。
- SSH 命令的参数必须经过 shell 引号处理。不得把用户输入直接拼接为未引用的 shell 语句。
- 密码不得出现在日志、命令行参数或 SSH 配置中。
- 每个任务使用独立的远程临时目录，结束后清理。
- 如果 SSH 连接中断、远程编码失败、下载不完整或输出检查失败，任务必须报告失败，并保留本地原始文件。
- 远程服务器上的临时文件可能包含尚未下载的媒体数据。若本机突然断电或网络中断导致清理请求无法执行，管理员可以按 `/tmp/ffmpeg-studio-*` 检查并清理遗留目录。

## 开发和测试

本地测试至少覆盖：

- SSH config 中单个别名和共享 `Host` 块的解析。
- 新增、修改、删除服务器后配置文件内容是否正确。
- 私钥路径、SSH Agent、跳转服务器和密码认证。
- Windows Credential Manager 的保存、读取和删除。
- SSH 连接失败、主机密钥变化和远程缺少 FFmpeg 的情况。
- 上传失败、远程编码失败、取消、暂停、下载失败和文件大小不匹配。
- MP4 与源容器输出、ZIP 内多个视频、PPTX 内多个视频。
- 任务成功、失败和取消后远程临时目录是否清理。

真实硬件编码必须在安装对应驱动的 NVIDIA、Intel 或 AMD 设备上验证。仅通过编码器名称探测不能视为硬件编码测试通过。
